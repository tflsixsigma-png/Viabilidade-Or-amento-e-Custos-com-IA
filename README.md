# Gestão de Custos de Projetos com IA — Portal do Curso

Ambientes interativos para ensinar gestão de custos de projetos com apoio de IA.
São páginas HTML **autossuficientes** (CSS e JavaScript embutidos): funcionam em
qualquer navegador, no computador ou no celular, **sem instalar nada e sem login**.

## Conteúdo

| Arquivo | O que é |
|---|---|
| `index.html` | Página-portal que lista e linka todos os materiais (abra este primeiro). |
| `jornada-custos-projeto.html` | Jornada didática — aprender fazendo (planejar, controlar, decidir). |
| `consultor-de-projetos.html` | Simulador principal: mesa de decisão executiva + pacote de prompts de IA. |
| `ficha-dados-caso.html` | Ficha de dados do caso ZapRango, para aplicar os prompts. |
| `exemplo-respostas-ia.html` | Exemplo de como a IA responde a cada prompt. |
| `gabarito-comentado-ZapRango.docx` | Gabarito comentado (Word), passo a passo das respostas. |

## Como publicar no GitHub Pages (≈5 minutos)

1. Crie uma conta em **github.com** (grátis) e clique em **New repository**.
   Dê um nome (ex.: `curso-gestao-projetos-ia`), marque **Public** e crie.
2. Clique em **Add file → Upload files** e arraste **todos os arquivos desta pasta**
   (os `.html`, o `.docx` e este `README.md`). Depois clique em **Commit changes**.
3. Vá em **Settings → Pages**. Em *Branch*, selecione **main** e a pasta **/(root)**.
   Clique em **Save**.
4. Aguarde ~1 minuto e recarregue a página. O GitHub mostrará o link público, algo como:
   `https://SEU-USUARIO.github.io/curso-gestao-projetos-ia/`
5. Esse link abre o **portal** (`index.html`). Compartilhe-o com a turma — cada aluno
   acessa todos os materiais a partir dele.

## Observação sobre a IA

O simulador **não depende de IA para funcionar**. Os prompts são fornecidos para o
aluno **copiar e colar** na IA de sua preferência (ChatGPT, Claude, Gemini etc.).
A geração automática de respostas dentro da página só ocorreria se o arquivo fosse
aberto dentro do Claude.ai; fora dele, o simulador simplesmente exibe o prompt para copiar.
